# 🍽️ Grilli – Restaurant Landing Page

A single-page website for a restaurant called **Grilli**, built with plain HTML, CSS, and JavaScript (no frameworks). It showcases the restaurant and its menu in a clean, appealing way, and is fully responsive across all screen sizes.

---

## 📌 About the Project

Grilli is a single-page website for a fictional restaurant, designed to showcase:
- The restaurant's identity (name, logo, contact info).
- The menu and featured dishes.
- The restaurant's story and strengths.
- An online table booking system.
- Contact details and location.

The project was built as practice for page layout, animations, and creating a complete UI using plain HTML/CSS/JS without any ready-made libraries.

---

## 🛠️ Tech Stack

- **HTML5** – for the page structure.
- **CSS3** – for styling and layout (Flexbox / Grid / Custom Properties).
- **JavaScript** – for interactivity (slider, menus, toggling elements).
- **Responsive design** that works on mobile, tablet, and desktop.

---

## ✨ Features

- **Hero Section with Auto Slider:** rotating restaurant images with different promotional taglines.
- **Menu Section:** food categories (breakfast, appetizers, drinks) with buttons linking to each section.
- **Our Story Section:** tells the history and philosophy of the restaurant.
- **Special Dish Section:** highlights the dish of the day with original and discounted prices.
- **Full Menu List:** cards for each dish with an image, name, price, and short description.
- **Testimonials Section:** displays customer reviews and experiences.
- **Online Table Booking:** a form to select number of guests, date, and time.
- **Contact & Location Info:** phone numbers, email, and lunch/dinner hours.
- **"Why Choose Us" Section:** icons highlighting the restaurant's strengths, such as hygiene and skilled chefs.
- **Upcoming Events Section:** cards for the latest events and articles.
- **Full Footer:** quick links, social media icons, and a newsletter subscription form.
- **Fully responsive design** across all screen sizes.

## 🚀 Running Locally

```bash
git clone https://github.com/Zeinab-Mahmoud/Grilli.git
cd Grilli
```

Then open `index.html` directly in your browser, or use an extension like **Live Server** in VS Code for a better experience.
